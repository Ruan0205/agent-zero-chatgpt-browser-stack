### project_check
Check the current chat's isolated project. Optional `test_command` runs one recognized test invocation (pytest, npm/pnpm/yarn test, go/cargo/dotnet test, vitest) in the same workspace as VS Code; if omitted, a test command is detected from project manifests. Optional `http_url` performs a read-only GET readiness check. Optional `container` reads Docker container state/health. Optional `timeout` is 1–600 seconds. This complements `vscode` and `text_editor`; it is not an editor, deployer or generic shell. Tests may create normal test outputs, so use the project's own test suite, then inspect failures before claiming success.
