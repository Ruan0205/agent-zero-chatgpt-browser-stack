### artifact_verify
Verify a real local file with `path`. Checks existence, size, SHA-256 and whether the format can be opened; supports image, PDF and ZIP checks plus generic files. `deep:true` additionally checks every ZIP entry CRC (can take a long time for large archives). `require_published:true` requires an attachment record in this chat, so a local file alone cannot be reported as delivered to the user. Paths must be within this chat's workspace/data, uploads or workdir. This tool only verifies: use `chatgpt_browser_media` to publish a missing attachment, then verify again.
