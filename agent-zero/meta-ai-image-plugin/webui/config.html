Meta AI pelo WhatsApp

Sessão dedicada para criar e editar imagens sem misturar com o WhatsApp pessoal do Agent Zero.

Informe DDI + DDD + número, somente dígitos. Este deve ser o número que conversará com a Meta AI.

Como conectar

  1. Digite o número com código do país e DDD.
  2. Clique em Conectar WhatsApp.
  3. No celular, abra Dispositivos conectados e escolha Conectar com número de telefone.
  4. Digite o código mostrado acima e aguarde o estado mudar para Conectado.
