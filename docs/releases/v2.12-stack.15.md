# v2.12-stack.15

Esta release substitui a correção parcial da v2.12-stack.14 por uma validação real
da interface e por uma fonte autoritativa de reconciliação.

## Correções

- O histórico recente é reaplicado a partir do servidor durante uma execução ativa,
  mesmo quando o WebSocket avançou seu cursor sem renderizar um lote no DOM.
- **Intervir agora** usa o estado durável `inflight`; o botão não fica desabilitado
  porque uma projeção transitória de `running` atrasou.
- Ao excluir um chat, mensagens e contexto ativo são removidos do SQLite. Um
  tombstone pequeno e persistente impede que workers atrasados ressuscitem o estado.
- A lista cumulativa `docs/REGRESSION_CHECKLIST.md` passa a registrar os problemas
  conhecidos, o cenário real obrigatório e a última evidência.

## Evidência da entrega

- 60/60 testes Python no Agent Zero principal;
- 60/60 testes Python no reparador;
- 17/17 testes Node da interface da fila;
- cenário real em navegador: evento posterior ao prompt sem reload, intervenção
  habilitada e renderizada, segunda mensagem preservada e navegação inalterada;
- exclusão do chat sintético: diretório ausente, zero mensagens, zero contexto
  ativo e tombstone presente.
