# v2.12-stack.14

Esta release corrige duas falhas de continuidade na interface do Agent Zero.

## Correções

- O histórico do chat é reconciliado periodicamente enquanto existe uma execução
  ativa. Assim, eventos como `A0: Calling LLM...` aparecem sem recarregar a página
  mesmo se o WebSocket perder uma atualização isolada.
- Cada item pendente ganhou a ação **Intervir agora**. Ela direciona a mensagem ao
  turno em processamento como uma correção, sem abrir uma segunda run.
- A fila continua durável: itens não escolhidos permanecem na ordem definida e uma
  interrupção entre entrega e confirmação não provoca perda nem replay cego.
- O envio inicial volta a ativar o acompanhamento automático do final do chat.

## Validação esperada

- testes Node da fila e da interface;
- testes Python do journal e do runtime dentro do container Agent Zero;
- compilação dos módulos Python e validações de Compose/integrações opcionais;
- teste real com uma mensagem ativa, duas mensagens pendentes e intervenção da
  segunda, confirmando que a terceira continua guardada.
