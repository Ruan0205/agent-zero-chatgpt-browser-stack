# v2.12-stack.16

Esta release corrige a ambiguidade visual que ainda fazia uma intervenção válida
parecer indisponível em chats Kimi.

## Correções

- **Intervir agora** aparece como botão textual durante uma execução ativa.
- O botão normal de enviar, que necessariamente ficava bloqueado, é ocultado nesse
  estado para não sugerir uma ação impossível.
- Nudge passa a se chamar **Retomar navegador** e fica desabilitado quando o chat
  usa Kimi ou quando o ChatGPT Browser ainda está processando.
- A fila explica permanentemente que **Retomar navegador** não envia mensagens.
- A automação real autentica pelo `.env`, sem pedir login ao operador e sem gravar
  credenciais no repositório.

## Evidência

- 23/23 testes Node da interface;
- 61/61 testes Python no principal e 61/61 no reparador;
- cenário real `VeSLhRA6`: botão textual visível e habilitado, envio bloqueado
  oculto, retomada desabilitada, intervenção entregue sem reload e segunda mensagem
  preservada;
- todos os chats sintéticos removidos, mantendo somente seus tombstones.
